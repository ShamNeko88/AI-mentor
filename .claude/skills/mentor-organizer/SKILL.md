# 目的
「その他」にたまったノートを整理し、新しいカテゴリフォルダの候補を提案する。

# 実行手順
1. output/notes/README.md（カテゴリ一覧）と既存フォルダ一覧を確認する。
2. output/notes/その他/ の全ノートを読み、テーマ・タグ・内容から似たもの同士をグループ化する。
3. 同じグループのノートが3件以上ある場合、新フォルダとして提案する。（件数の基準は仮置き。ユーザーの指示があれば従う）
   - 既存フォルダに当てはまるものは、そのフォルダへの移動を提案する。
4. 提案を次の形で報告する。
   - 提案するフォルダ名
   - 対象ノートの一覧（ファイル名）
   - そう判断した根拠（共通のタグ・内容）
5. ユーザーが承認した分だけ、フォルダを作成してノートを移動する。
6. 新しいフォルダを作ったら、output/notes/README.md に「- カテゴリ名: 内容の説明（一行）」を追記する。

# ルール
- 承認なしにフォルダの作成・ノートの移動をしない。
- ノートの内容は書き換えない。移動のみ行う。（ファイル名も変えない）
- 移動先に同名ファイルがある場合は上書きせず、ユーザーに確認する。
- 3件に満たないグループは提案せず、「まだ分類しない」と報告する。
- フォルダ名は既存の表記に合わせる。（例: AWS と aws を混在させない）
- ノートの内容にある機密情報は、報告に引用しない。
- 「その他」にノートがない場合は、その旨を伝えて終了する。
