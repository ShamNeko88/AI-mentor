# AI-Mentor

勉強や業務の相談に乗ってもらいながら、その過程を学習ノートとして記録するプロジェクトです。
ノートは、後の復習・問題作成・振り返りの材料になります。

```
相談・支援 → 学習ノート作成 → 問題作成 → 振り返り
                  ↑ 現在はここまで    ↑ 今後追加予定
```

## 現在の機能

- エージェント mentor: 勉強・業務の相談に乗るメンター役
- スキル /mentor-note: 相談内容を学習ノートにまとめて保存する

未実装（今後追加予定）: mentor-quiz（ノートから問題を作る）、mentor-review（期間を指定して振り返りを作る）

## フォルダ構成

```
AI-Mentor/
├─ CLAUDE.md                          # このプロジェクトの共通ルール
├─ README.md                          # このファイル
├─ .claude/
│   ├─ agents/mentor.md               # メンター役の定義
│   └─ skills/mentor-note/SKILL.md    # ノート作成スキル
└─ mentor/
    └─ notes/                         # 学習ノートの保存先（yyyymmdd_テーマ.md）
```

## 使い方

1. AI-Mentor フォルダでClaude Codeを起動する。
2. そのまま勉強や業務の相談をする。会話は自動的にメンターの方針で応答される（CLAUDE.mdに設定済み）。
3. 区切りのよいところで /mentor-note を実行する。
4. mentor/notes/yyyymmdd_テーマ.md にノートが保存される。

ノートには次の内容が入ります。

- 目的、分類（勉強 / 業務）、タグ
- 学んだこと・決まったこと
- つまずいた点・誤解していた点
- 残っている疑問、次にやること
- 復習・問題作成用メモ

## 注意点

- 記録していない相談は残らない。 Claudeはセッションをまたいで会話を覚えていないため、後で使えるのはノートに保存した内容だけです。セッションを終える前に /mentor-note を実行してください。
- 機密情報を書かない。 APIキー、パスワード、個人情報、業務上の機密情報はノートに入れないでください。
- ノートの内容は確認する。 会話から自動でまとめるため、誤解や抜けがないか、保存後に目を通してください。
- 同名ファイルは上書きしない。 同じ日付・テーマのノートがある場合は、追記か別名かを確認されます。
- スマホでの利用は想定していない。 現在はPCのClaude Codeで使う前提です。

## ルールの置き場所

- 共通ルール: CLAUDE.md
- メンターの方針: .claude/agents/mentor.md
- ノートの形式: .claude/skills/mentor-note/SKILL.md

ノートの形式を変えたいときは、SKILL.md を編集します。
