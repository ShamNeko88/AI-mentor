# AI-Mentor

勉強や業務の相談に乗ってもらいながら、その過程を学習ノートとして記録するプロジェクトです。
ノートは、後の復習・問題作成・振り返りの材料になります。

```
相談・支援 → 学習ノート作成 → 問題作成 → 振り返り
                                                    ↑ 現在はここまで
```

## 機能

- mentor（エージェント）: 勉強・業務の相談に乗るメンター役。常時有効
- /mentor-note（スキル）: 相談内容を学習ノートにまとめて保存する
- /mentor-quiz（スキル）: カテゴリのノートから問題を作り、1問ずつ対話式で出題する
- /mentor-organizer（スキル）: 「その他」のノートを整理し、新しいカテゴリフォルダを提案する
- /mentor-review（スキル）: 指定した期間のノートを要約し、振り返りを作る

## 使い方

1. AI-Mentor フォルダでClaude Codeを起動する。
   start-claude.bat（Windows）または start-claude.command（Mac）をダブルクリックでも起動できる。
   Macで初回に動かない場合は、chmod +x start-claude.command を実行する。
2. そのまま勉強や業務の相談をする。（CLAUDE.md の設定で、自動的にメンターとして応答される）
3. 区切りのよいところで /mentor-note を実行する。
   → output/notes/<カテゴリ>/yyyymmdd_テーマ.md に保存される。
4. 復習したいときは「/mentor-quiz AWS」のようにカテゴリを指定して実行する。
5. 期間ごとに振り返りたいときは /mentor-review を実行する。（期間は実行時に確認される）

## 注意点

- 記録していない相談は残らない
  Claudeはセッションをまたいで会話を覚えていません。終える前に /mentor-note を実行してください。
- 機密情報を書かない
  APIキー、パスワード、個人情報、業務上の機密情報はノートに入れないでください。
- output/ はGitに保存されない
  .gitignore で無視されます。バックアップは別途取ってください。
  別の環境では、output/ フォルダごとコピーすれば引き継げます。
- ノートは保存後に目を通す
  会話から自動でまとめるため、誤解や抜けがあるかもしれません。
- 同名ファイルは上書きしない
  追記か別名かを確認されます。
- PCのClaude Codeで使う前提です。（スマホは想定していません）

# 詳細

## フォルダ構成

```
AI-Mentor/
├─ CLAUDE.md                          # 共通ルール
├─ README.md                          # このファイル
├─ start-claude.bat                   # Windows用の起動ファイル
├─ start-claude.command               # Mac用の起動ファイル
├─ .claude/
│   ├─ agents/
│   │   └─ mentor.md                  # メンターの方針
│   └─ skills/
│       ├─ mentor-note/SKILL.md       # ノートの形式・保存先の決め方
│       ├─ mentor-quiz/SKILL.md       # クイズの出題・記録
│       ├─ mentor-organizer/SKILL.md  # 「その他」の整理
│       └─ mentor-review/SKILL.md     # 振り返りの作成・記録
└─ output/                            # すべてのデータ（別環境へはこのフォルダを移す）
    ├─ review/                        # 振り返り（yyyymmdd-yyyymmdd.md）
    ├─ quiz/                          # クイズ記録（yyyymmdd_カテゴリ.md）
    └─ notes/                         # 学習ノート
        ├─ README.md                  # カテゴリ一覧と一行の説明
        ├─ AWS/                       # カテゴリごとのフォルダ（例）
        │   └─ yyyymmdd_テーマ.md
        ├─ Snowflake/
        └─ その他/                    # どのカテゴリにも当てはまらないノート
```

- カテゴリは技術分野（AWS、Snowflake など）で分けます。勉強/業務の区別はフォルダではなくタグで行います。
- 複数のカテゴリにまたがるノートは、主なカテゴリのフォルダに保存し、他のカテゴリはタグに入れます。
- 新しいカテゴリフォルダを作る前には確認されます。作ったあとは、output/notes/README.md に説明が追記されます。
- ルールや形式を変えたいときは、上の各ファイルを編集します。（例: ノートの形式は SKILL.md）

## 応答の深さ

トークン消費を抑え、記録だけのチャットを邪魔しないため、応答は使い分けられます。

- 詳しく答える（明確な依頼があったときだけ）
  「教えて」「〜って何？」「〜について説明して」「〜についてまとめて」「問題を出して」「分からない」
- 一言で受け取る（上記以外）
  「今日は〇〇をやった」などの報告や記録。解説、確認質問、提案はされません。
- 迷う発言
  「解説しますか？」と聞かれます。

## 保存の確認

保存し忘れを防ぐため、次のタイミングで「ここまでをノートにまとめますか？」と聞かれます。

- 話題が一区切りついたとき
- 「ありがとう」「今日はここまで」など、終わりそうな発言をしたとき
- まとめていないまま、同じ話題で長くやり取りしたとき

断ると、同じ話題ではしばらく聞き直されません。「はい」と答えると、そのままノートが作成されます。

ノートの内容: 目的・分類（勉強/業務）・タグ、学んだこと・決まったこと、つまずいた点、残っている疑問・次にやること、復習・問題作成用メモ。

## クイズ

「/mentor-quiz AWS」のように、カテゴリフォルダを指定して実行します。

- 出題前に、カテゴリと出題数を確認されます。
- ノートの「復習・問題作成用メモ」などから問題が作られ、1問ずつ出題・採点されます。
- 結果は output/quiz/yyyymmdd_カテゴリ.md に保存されます。

## 振り返り

/mentor-review を実行すると、期間内のノートの要約を作ります。

- 実行のたびに、振り返る期間（開始日と終了日）を確認されます。
- 全カテゴリのノートから、ファイル名の日付が期間内のものが対象です。
- 結果は output/review/yyyymmdd-yyyymmdd.md（開始日-終了日）に保存されます。

## 「その他」の整理

「その他」にノートがたまってきたら、/mentor-organizer で整理します。

- 似た内容のノートが3件以上あるグループを、新しいカテゴリフォルダとして提案します。（3件は仮の基準）
- フォルダの作成とノートの移動は、承認した分だけ行われます。ノートの内容やファイル名は変わりません。
